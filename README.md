## 🔍 Verificar Integridad

Cada descarga incluye un archivo `checksums.txt` con el hash SHA256.

```powershell
# Windows PowerShell:
certUtil -hashfile Gymbrot.exe SHA256
# Compara con el valor en checksums.txt
```
